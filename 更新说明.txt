================================================

1.0.8   2026-11-01
------------------------------------------------
· 两个伤害统计框现在能拿鼠标拖着走，也能拉大小。

  按住框里空白处拖 = 挪到任意位置。
  按住右下角（鼠标变成斜箭头）拖 = 改宽改高。
  双击一下 = 高度恢复成「跟着技能条数走」，多了自动长、少了自动缩。

  拖完不用点保存，位置记在同目录的 box_layout.json 里，下次开游戏还
  在原处。换了显示器、位置跑到屏幕外，会自动回到左上角。

  注意：这两个框现在能点到了（以前整层是穿透的）。为了防止点它把游戏
  窗口的焦点抢走（那样按 1/2/3 选卡就废了），窗口加了「不抢焦点」的
  标志，点完照常按键盘。

· 选卡时按流派提示该拿哪张。

  新法术卡经常被同一条上限压住，三张牌都显示 ≈+30%，看数字分不出
  好赖。现在会看你「04 流派」里选的那条：

      你选的是痛苦流 → 牌里有「腐蚀术」「痛苦诅咒」
      这两个是痛苦流的核心 → 徽标变成暗金底 + 「★ 流派 ≈+11.8%」
      「献祭」不在痛苦流里 → 还是普通的绿字，不带流派标记

  规矩是：只要这三张里有流派核心，星号就只在核心之间比，杂牌数字再大
  也抢不走这个标记。两张都是核心时（比如腐蚀术 + 痛苦诅咒），两张都
  标「★ 流派」，看后面那个百分比挑高的拿。

  没选流派的话，这个标记不会出现，跟以前一样。

1.0.7   2026-11-01
------------------------------------------------
· 伤害统计拆成两块，并排挂在左上角。

  左边「造成伤害」：这一把所有怪一起算。
  右边「首领伤害」：只算跟精英 / 首领交手的那几段。

      造成伤害          961.0 DPS  |  首领伤害         992.9 DPS
      -----------------------------|-----------------------------
      1 腐蚀术  17.0万   44.0%    |  1 痛苦诅咒 4.2万   44.6%
      2 灵魂之火 12.0万  31.0%    |  2 暗影箭   1.7万   18.2%
      3 暗影箭    9.6万  25.0%    |  3 吸取生命  6400    6.8%
      4 献祭      1.2万   3.0%    |  4 死亡缠绕  3200    3.4%

  游戏自带那个统计框一次只能显示一种，想看另一种得点一下切换，打起来
  根本腾不出手。现在两个一直并排挂着，不用切。

  样式往游戏原生那栏靠：深色底 + 金边 + 标题栏，名次按 1 红 2 蓝 3 金
  4 绿 5 紫上色，第六名往后压灰，伤害数字白色右对齐，占比灰字跟在后面。

  右边那格还没跟大怪打过时写「尚未与首领交战。」

  开关还是原来那一个：悬浮层 -> 显示伤害统计框，两个一起开一起关。

  ⚠ 游戏自带那个统计框（带「重置」按钮的）建议点右上角 X 关掉，
    不然会和我们这两个叠在一起。

· 修「献祭 +50% 会被算得比腐蚀术 +5% 高」。

  你举的例子正中要害，查下来是这么回事：
  一个技能这一把还没打出过伤害时，程序不知道该按多少占比算，就按
  「次要技能 8%」兜底。于是：
      献祭   +50% × 8%  = +4.0%
      腐蚀术  +5% × 44% = +2.2%   ← 主力反而输了
  现在兜底改成 3%，而且小字会明写「估3%」，一眼能看出这个数是估的。
  同一个例子现在的结果：
      腐蚀术  +5% × 44% = +2.2%
      献祭   +50% × 3%  = +1.5%   ← 不再反超

  顺带说明：卡面小字本来就会写「占44%×+5%伤害」，那个 44% 就是这张卡
  跟你当前主力的关联度。占比越高，说明这张卡越压在刀口上。

1.0.6   2026-11-01
------------------------------------------------
· 新增「伤害统计」框，照游戏原生那个框做的。

  游戏画面左侧常驻一块，每个技能一行，写着打了多少、占总伤害多少：

      伤害统计                    961.0
      ────────────────────────────────
      1  腐蚀术        17.0万      44%
      2  灵魂之火      12.0万      31%
      3  暗影箭         9.6万      25%
      4  献祭           1.2万       3%
      ────────────────────────────────
      精英 992.9

  第一名是金色，二三名亮白，往后的暗一点，跟游戏里那一栏的观感接近。
  底部那个「精英」= 只算打大怪（精英 / Boss）那段时间的平均 DPS。

  不想要：工具箱 → 悬浮层 → 取消勾选「显示伤害统计框」。

· 流派提示改成「只在选卡时出现」。
  之前它是常驻的，会一直占着右边。现在只有卡牌弹出来的时候才跟着出现，
  选完卡立刻收起来，打怪时屏幕是干净的。
  想要它一直挂着的话，暂时没有这个选项，跟我说一声我加。

· 修「开关一下悬浮层会卡半秒」。三处原因：
  1. 每 0.2 秒把 state.json 整份重新解析一遍，那是个十几 KB 的 JSON，
     带着两张伤害表。现在先看文件变没变，没变就复用上一次的结果。
  2. 每 0.2 秒无条件重设四个徽标的位置和文字。WinForms 每次设都会触发
     重排 + 重绘，而这个窗口是覆盖全屏的，一次重绘就是整整一屏。
     现在内容没变就一个控件都不碰。
  3. 两块面板都改成了双缓冲，不再闪。
  另外读取间隔从 0.2 秒改成 0.25 秒 —— 后台本来就是每 0.25 秒写一次，
  读得比写得勤只是白干活。

· 清理 GitHub 仓库。
  以前每次发版会把旧版本的完整包（一个 12MB）、Python 缓存 __pycache__、
  还有我这台机器的设置文件一起传上去，堆着占地方。现在发版时自动清掉。

1.0.4   2026-11-01
------------------------------------------------
· 新增「流派」页 —— 这一版的主角。

  它把游戏客户端里的天赋树翻译成一张「该带什么」的清单。
  选中一条流派之后，左边直接列出来：

    · 这条路的技能优先级（先练哪个、后练哪个）
    · 每个技能你练到几级了，没练的写「缺少」
    · 这条路推荐的项链 / 戒指 / 饰品，戴着的报等级，没有的写「缺少」
    · 每件首饰干什么用（比如「持续伤害跳速 +36%」）

  流派名称是照客户端天赋树来的：痛苦 / 恶魔学识 / 毁灭。
  其中毁灭树里暗影箭和灼热之痛是两条不同的路，
  所以拆成「暗影」和「火焰」两条；恶魔学识树拆成「单体」和「铺场」。

  术士一共 5 条：痛苦、暗影、火焰、恶魔·单体、恶魔·铺场。

· 伤害统计重做：现在同时给「整体 DPS」和「对精英 DPS」两列，
  每个技能还能看到它打大怪时占多少。
  以前只有一个总数，看不出自己打大怪到底行不行。

  说明一下：对精英的 DPS 比整体高是正常的 —— 它只统计打大怪那段时间，
  清小怪的时间不算进去，所以数字会更高，不是算错。

· 修复「身上戴的首饰一直识别不到」。
  游戏内存里装备有两种写法，三段的和四段的：
      amulet:fire_lord:r1                （炎魔之王项圈 1 级）
      amulet:legendary:corruption:r7     （腐蚀术词缀 7 级）
  以前只认四段那种，所以你明明戴着炎魔之王项圈，插件却当没有。
  现在两种都认。换装卡的收益计算也跟着变准了。

1.0.3   2026-11-01
------------------------------------------------
· 修复「点了开始，悬浮层灯是灰的、游戏里一个徽标都不显示」。
  悬浮层是 PowerShell 写的，启动时我给它加了 DETACHED_PROCESS 这个标志。
  实测发现：带上它就一定秒退（退出码 0，一声不响），去掉就正常。
  现在改成只留 CREATE_NO_WINDOW，悬浮层能稳定拉起来。
  同时把悬浮层的错误输出接到 logs\overlay.err —— 以后再出问题，
  顶栏会直接显示 PowerShell 报的原话，而不是只写一句「启动失败」。

· 修复「技能数值页读取失败：定位技能表失败 [WinError 2]」。
  原因是技能表模块按「程序目录的上一级」去找游戏 exe。
  从 AZS-DpsGain\dist\ 里启动时，上一级是 AZS-DpsGain，那里没有 exe，
  所以报「系统找不到指定的文件」。
  现在上一层找不到时，会回头查工具箱里存的游戏目录，哪儿启动都能读到。

· 打包规则：以下划线开头的文件一律当开发脚本，不再混进更新清单。

· 发版工具加了一条 python publish.py --sync，
  自动把 dist 倒进 GitHub 本地仓库，不用手动复制（以前容易漏文件或套多一层）。

1.0.2   2026-11-01
------------------------------------------------
· 修复「换装卡算出来的收益虚高」—— 这是这一版最重要的一条。

  项链、戒指、饰品只能戴一件。以前算这类卡时，只算了「新卡给你什么」，
  没算「换上去会失去什么」，所以：

    · 一条已经戴在身上的项链，再看到它低等级的版本，会显示 +105%（其实是降级）
    · 换另一种项链，显示 +44%（其实换过去是亏的）

  现在会先去读你身上那件是几级（游戏自己会上报），再按两边的实际数值
  算净账。同名牌换等级、换另一条项链，都会扣掉失去的那部分。

· 修复「+X% 伤害」没算进已有的伤害池。
  伤害是加法池：你已经堆了 247% 的时候，再来一件 +152% 的装备，
  实际是 (247+152)/247 = 1.62 倍，不是 2.52 倍。以前按 2.52 算，虚高约 55%。

· 修复「30% 几率再次打击，造成 100%」这类效果完全没被算进去。

1.0.1   2026-11-01
------------------------------------------------
· 修复「双击启动器没反应，只看到一屏报错」的问题。
  原因是启动脚本用了 Linux 那种换行格式，Windows 的命令行读到这种文件会把
  整段命令拆错，于是出现一堆「'XXX' 不是内部或外部命令」。现在统一成 Windows
  格式 + GBK 编码，中文提示也能正常显示了。

· 修复「换了台没装过 Python 的电脑，所有入口都说找不到运行时」。
  以前只有主启动器知道去找包里自带的 runtime 目录，技能面板、还原原值、
  存档修改器这几个入口都不知道，在人家的电脑上必然失败。现在六个入口
  全部按同样的顺序找：包内 runtime → 本机 Python。

· 修复 run.cmd / restart-tools.cmd 里写死了别人电脑路径的问题
  （C:\Users\Administrator\...），换台电脑就找不到 Python。

· 补上两个漏打包的文件：改档工具的入口「存档修改器.cmd」，
  以及「技能面板.cmd」「还原原值.cmd」实际调用的 spellpanel.py /
  restore_orig.py。以前包里只有 .cmd 没有 .py，点了必然失败。

· 发版工具加了自动检查：以后凡是 .cmd 文件格式不对，打包时会自动纠正，
  同一个坑不会踩第二次。


1.0.0   2026-11-01
------------------------------------------------
· 全新的一体化界面：把悬浮层、技能数值、方案天赋、更新合并进一个窗口
· 游戏内热键：F8 显示 / 隐藏收益徽标，F9 把工具箱叫到最前
· 方案与天赋：支持多套方案切换，天赋开关、DoT 存活时间、吞噬间隔都能调
· 一键更新：改了代码之后，朋友那边点一下就能升级，只下载变了的文件
· 修复技能表定位：游戏 11-01 更新插入了一个新技能，旧代码会把技能数从
  113 截成 65（法系技能全丢）。改成容错计数后恢复正常，并且以后再加技能
  也不会再断。
· 修复日志时间戳解析：日志行首带 ANSI 颜色码，导致所有事件时间都退回
  「读到的当下时间」，重启插件时可能把上一局的旧卡当成新卡显示。
· 修复存档修改器的游戏路径：以前写死在某个固定盘符，换台电脑就在启动瞬间
  崩掉，连错误日志都写不出来，现象只是「点了没反应」。现在会自动找游戏目录。
· 存档修改器加了启动自检：它靠调用游戏 exe 里的解密函数工作，游戏更新后这些
  函数会挪位置。现在对不上时会弹一句说明，不会闪退、不会碰你的存档。

已知限制
------------------------------------------------
· 流派目前只整理了术士 5 条。想先确认这套判断逻辑对不对，
  再照同样的做法铺开其他 8 个职业。其他职业进「流派」页会显示「还没有数据」。
· 流派只说明「这张卡是不是在强化你这条路」，不代表这条路本身更强。
  火系对比冰系谁厉害，得靠你自己打出来。
· 恶魔两条流派主要靠被动召唤，插件暂时没法用伤害记录验证它有没有跑起来，
  页面上会标一句提醒。
· 只有圣骑士 / 术士 / 牧师内置了完整的职业规则，其他职业走通用规则，
  结果会粗一些。
· 插件读不到游戏里的天赋树，「点了什么天赋」需要自己在「方案与天赋」里勾。
· 持续时间卡不扣除「怪提前死、DoT 跳不完」的损失，只通过「怪能活多久」
  这个参数近似。
· 存档修改器暂时跟不上 11-01 这版游戏（游戏内部函数换位置了）。
  如果你的存档要改，先在旧版游戏上用；等这里适配之后会恢复正常。
